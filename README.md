# Early Church Writings

An offline Android library of the Ante-Nicene and Nicene/Post-Nicene Fathers (public-domain Schaff edition), with search, a reader, a catalog, themes, the BSB and WEB Bibles, and saved quotes.

**Download the latest version:** [EarlyChurchWritings-1.2.0.apk](https://raw.githubusercontent.com/jarjoems-stack/early-church-writings-releases/main/EarlyChurchWritings-1.2.0.apk)

Open the file on your Android phone and tap Install (allow installs from your browser or files app if asked). The app checks here for updates and offers them inside the app.
